Finding a dataset

Criteria for datasets

The data sets should meet the following criteria:

  • At least 200 observations.

  • At least 8 columns.

  • At least 6 of the columns must be useful and unique explanatory variables.

    • Identifier variables such as “name”, “social security number”, etc. are not useful explanatory variables.
    • If you have multiple columns with the same information (e.g. “state abbreviation” and “state name”), then they are not unique explanatory variables.

  • You may not use data that has previously been used in any course materials, or any derivation of data that has been used in course materials.

Please ask the instructor if you’re unsure whether your data set meets the criteria.

If your hearts are set on a dataset that has fewer observations or variables than what’s suggested here, that might still be ok; use these numbers as a guideline for a successful proposal, not as minimum requirements.

Components

For each data set, include the following:

Introduction and data

For each data set, provide a written introduction and description, making sure to explain what each observation describes. Provide a citation for the data (author, year of publication, dataset title, publisher/repository, and the DOI/URL).

Research question

Your research question should contain at least three variables, and should be a mix of categorical and numerical variables. When writing a research question, please think about the following:

  • What is your target population?

  • Is the question original?

  • Can the question be answered?

For each data set, include the following:

  • A well formulated research question. (You may include more than one research question if you want to receive feedback on different ideas for your project.)

  • Statement on why this question is important.

  • A description of the research topic along with a concise statement of your hypotheses on this topic.

  • Identify the types of variables in your research question. Categorical? Numerical?

Glimpse of data

For each data set:

  • Place the file containing your data in the data folder of the project repo.
  • Use the glimpse() function to provide a glimpse of the data set.

Data dictionary

For each data set, add a data dictionary to the README.md file in the data folder describing each variable.

Grading

Total 10 pts
Introduction and data 2 (1 pt for each dataset)
Research question 2 (1 pt for each dataset)
Glimpse of data 2 (1 pt for each dataset)
Data dictionary 2 (1 pt for each dataset)
Workflow and formatting 2

Each of the first four components will be graded as follows:

  • Meets expectations (full credit): All required elements are completed and are accurate. The narrative is written clearly, all tables and visualizations are nicely formatted, and the work would be presentable in a professional setting.

  • Close to expectations (half credit): There are some elements missing and/or inaccurate. There are some issues with formatting.

  • Does not meet expectations (no credit): Major elements missing. Work is not neatly formatted and would not be presentable in a professional setting.

Additionally, the workflow component will be graded based on:

  • organization
  • code style
  • informative commit messages
  • commits from each team member
Important

Each team member must contribute, with commits, to the project proposal in order to be eligible for full credit for workflow and formatting.

It is critical to check feedback on your project proposal. Even if you earn full credit, it may not mean that your proposal is perfect.
