Lab 6

Houses in Duke Forest

Lab

Introduction

In this lab you’ll return to the Duke Forest housing data from class and use simulation-based inference in two ways: a bootstrap confidence interval to quantify the uncertainty in an estimated slope, and a randomization test to decide whether an observed relationship could plausibly be due to chance alone.

Learning objectives

By the end of the lab, you will…

  • Construct a bootstrap distribution for a regression slope and use it to build percentile confidence intervals.
  • Interpret a confidence interval for a slope.
  • State null and alternative hypotheses about a slope.
  • Generate a null distribution by permutation, compute a p-value, and state a conclusion in context.

Checking your work

This lab is autograded. That changes two things about how you work:

  1. Answers go into named objects. Each question below tells you exactly what to name your answer (e.g., “save the model as bed_fit”), and the template’s code cells already contain placeholders such as bed_fit <- NULL with a short comment describing what goes there. Replace the NULL (or NA) with your code, but do not change the object names. The autograder looks for these exact names; an answer stored under a different name receives no credit, even if the code is correct.

  2. You can check your answers as you go. After each question, the template contains a check chunk that runs ottr::check() on that question. Run it to see the results of the public checks: quick tests that confirm your answer has the right structure (a fitted model, a bootstrap distribution with the right number of replicates, and so on). These checks are designed to tell you whether you’re on the right track without revealing the answer.

  3. The last check chunk checks your code style. It reports any lines that do not follow the course style guidelines (see below), with line numbers, so you can fix them before submitting.

NoteMultiple choice and short answers

Some questions ask you to record an answer by assigning a value to a variable. Letters must be typed as strings (in quotes), for example q1_slope_interp <- "B". Numeric answers are typed as numbers without quotes, for example q1_slope <- 1000.

Passing all public checks does not guarantee full credit. When your submission is graded, additional hidden tests check your answers for full correctness. Data

The data come from the duke_forest dataset in the openintro package and describe 98 houses sold in the Duke Forest neighborhood of Durham, NC in November 2020, scraped from Zillow. They are provided as duke_forest.csv in the data folder, and the template reads them in with:

duke_forest <- read_csv("data/duke_forest.csv")

The variables used in this lab are:

Variable Description
price Sale price, in USD
bed Number of bedrooms
lot Area of the entire property, in acres
year_built Year the house was built

Part 2 - Is lot size related to the age of a house?

Duke Forest was developed over many decades. One might wonder whether the earliest houses were built on larger lots, before land in the neighborhood became scarce. Or perhaps the opposite is true, and newer houses were built on larger lots as the neighborhood expanded outward. Since we don’t have a reason to expect one direction over the other, in this part you’ll test whether there is any relationship between lot size and the year a house was built.

One house has no recorded lot size, so the template removes it first:

duke_lot <- duke_forest |>
  filter(!is.na(lot))

Use duke_lot for the rest of the lab.

4b. Fit a linear regression model predicting year_built from lot and save it as lot_fit. Display a tidy summary of the model output.

Question 6

6b. Generate the null distribution: specify the model, state the null hypothesis of independence, generate 1,000 permutations, and fit the model to each. Save the result as null_fits. The set.seed(1234) line is already in the template immediately before this step; leave it in place.

6c. Visualize the null distribution and save the plot as null_hist. You may use visualize(), which shows the null distributions of both the intercept and the slope for lot side by side; the panel for lot is the one of interest. Alternatively, you may make a histogram of only the lot slopes with ggplot().

6d. Record in q6_center the option that best describes the null distribution of the slope for lot:

A. It is centered near 0, because permuting breaks the relationship between the two variables.

B. It is centered near the observed slope, because each permutation resembles the original sample.

C. It is centered near 0.6, the average lot size in the sample.

D. It is centered near 1,000, the number of permutations that were generated.
